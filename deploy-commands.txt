📍 ШАГ 1: ЗАГРУЗКА НА GITHUB
───────────────────────────────────────────────────────────────

1. Создайте репозиторий на https://github.com/new
   Название: rental-analyzer

2. Выполните команды (замените YOUR_USERNAME):

cd C:/Users/pavel/rental-analyzer
git remote add origin https://github.com/YOUR_USERNAME/rental-analyzer.git
git branch -M main
git push -u origin main

───────────────────────────────────────────────────────────────

📍 ШАГ 2: ДЕПЛОЙ НА VERCEL
───────────────────────────────────────────────────────────────

1. Откройте: https://vercel.com
2. Sign Up → Continue with GitHub
3. Add New → Project
4. Import: rental-analyzer

Настройки:
- Framework Preset: Other
- Root Directory: ./
- Build Command: cd client && npm install && npm run build
- Output Directory: client/build

───────────────────────────────────────────────────────────────

📍 ШАГ 3: ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ В VERCEL
───────────────────────────────────────────────────────────────

Environment Variables → Add:

NODE_ENV=production

STRIPE_SECRET_KEY=sk_test_51...
  (получить на https://dashboard.stripe.com/apikeys)

STRIPE_PUBLISHABLE_KEY=pk_test_51...
  (получить на https://dashboard.stripe.com/apikeys)

REACT_APP_STRIPE_PUBLISHABLE_KEY=pk_test_51...
  (тот же что и выше)

ANTHROPIC_API_KEY=sk-ant-...
  (получить на https://console.anthropic.com)

EMAIL_HOST=smtp.gmail.com

EMAIL_PORT=587

EMAIL_USER=your@gmail.com

EMAIL_PASSWORD=your_16_digit_app_password
  (получить на https://myaccount.google.com/apppasswords)

APIFY_API_TOKEN=optional_token
  (опционально, для парсинга реальных данных)

───────────────────────────────────────────────────────────────

📍 ШАГ 4: ДЕПЛОЙ
───────────────────────────────────────────────────────────────

Нажмите "Deploy" в Vercel

Ждите 2-5 минут

Готово! Ваш URL: rental-analyzer.vercel.app
